# 一账清欢 💰

> 一个给自己记账、攒钱、规划旅行开销的小管家。纯前端，数据只存在你自己的浏览器里。

## ✨ 功能

- **账户分区**：生活费 / 存款 两个账户，收支分开管
- **记账**：收入/支出 + 快捷键、自定义分类、值/不值标签
- **生活费月度分配**：本月生活费分配到各分类，超分配标红
- **收入台账**：按来源汇总收入（累计 + 本月）
- **月度预算 + 分类预算**：超支自动预警
- **净资产走势**：近 6 月你的钱在变多还是变少
- **应急金 / 短期·长期储蓄目标 / 想要清单**：进度条攒钱
- **消费决策尺子**：买之前 4 个问题，帮你判断值不值
- **月度总结**：每月写复盘，随时回看

## 🧱 技术栈

- 纯前端单文件 `index.html`，零依赖、零构建
- localStorage 存数据（**设备独立**，靠「导出/导入备份」同步）
- 图表用原生 CSS/SVG，深浅色自动切换

## 🚀 本地运行

双击 `index.html` 即可。数据存在本机浏览器，换设备记得「导出备份」。

## 📱 部署到手机

把 `手机版/` 文件夹拖到 Netlify Drop，即可手机访问。
